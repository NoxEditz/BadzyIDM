## 📌 نبذة عن المشروع

**Badzy** برنامج سطح مكتب لنظام ويندوز كُتب بلغة **Rust** وواجهته بمكتبة **Slint**. يجلب الملفات من الروابط التي يحددها المستخدم ويحفظها على جهازه.
يقسّم الملف على عدة اتصالات لتسريع التحميل، ويستأنف من حيث توقف إذا انقطع الاتصال، ويحمّل الفيديو والصوت من الصفحات وقوائم التشغيل، ويدعم التورنت وروابط الماجنت. وتعمل معه إضافة للمتصفح تسلّمه التحميلات تلقائيًا.

> [!NOTE]
> Badzy مبني على **Ezoo Download** من تطوير Ahmed Ezzat. التفاصيل وتراخيص المكونات الأخرى في ملف `THIRD-PARTY-NOTICES.txt`.

> [!IMPORTANT]
> يتحمّل المستخدم مسؤولية احترام حقوق الملكية وشروط استخدام أي محتوى يتعامل معه من خلال البرنامج.

## 🆕 ما الجديد في هذا الإصدار

- **واجهة جديدة بالكامل:** نافذة بلا إطار ويندوز بحواف دائرية (تعمل على ويندوز 10 أيضًا)، وشريط عنوان خاص، وقائمة جانبية قابلة للطي، وبطاقة التحميلات النشطة، وأيقونات حادة، وحركات سلسة.
- **شعار واحد في كل مكان:** الأيقونة والمهام والتراي والمثبّت.
- **نافذة التقدم:** لا وميض عند التحديث، وزر إظهار/إخفاء التفاصيل يعمل بثبات.
- **تحميل أسرع وأكثر ثباتًا:** كتابة مجمّعة على القرص، وانتظار تلقائي عند ردود 429 و503، وتنظيف الملفات المؤقتة اليتيمة.
- **ffmpeg مرفق:** نسخة LGPL مبنية خصيصًا، فلا حاجة لتثبيت شيء آخر.
- **إضافة 2.1.0:** عربي وإنجليزي، قائمة مواقع مستثناة، أنواع ملفات إضافية، علامة ✓ على الأيقونة، اختصارات لوحة المفاتيح، ونسخ احتياطي للإعدادات.

## 📦 التثبيت

1. افتح صفحة [**Releases**](../../releases) وحمّل الملف **`Badzy v0.1.exe`**.
2. شغّله وأكمل المعالج. يُثبَّت البرنامج للمستخدم الحالي ولا يحتاج إلى صلاحيات المسؤول، ويأتي معه `ffmpeg` و`yt-dlp` و`aria2c` وملفات الإضافة.
3. ثبّت إضافة المتصفح من [القسم التالي](#-إضافة-المتصفح).

يحتاج البرنامج إلى **Windows 10 أو 11 (64-bit)** واتصال بالإنترنت.

## 🧩 إضافة المتصفح

تجد ملفات الإضافة في مجلد `extension` داخل مجلد تثبيت Badzy (وفي هذا المستودع أيضًا). افتح البرنامج مرة واحدة ثم:

**Chrome / Edge / Brave**
1. افتح `chrome://extensions` أو `edge://extensions` وفعّل **Developer mode**.
2. اختر **Load unpacked** وحدد مجلد `extension`.
3. ثبّت أيقونة Badzy في شريط المتصفح.

**Firefox**: استخدم مجلد `extension-firefox` المرفق مع البرنامج (`about:debugging` ← This Firefox ← Load Temporary Add-on)، أو ملف `badzy-firefox.xpi` الموقّع إن وُجد في الإصدار.

### ماذا تفعل الإضافة؟

| الميزة | التفاصيل |
|---|---|
| ⬇️ **التقاط التحميلات** | تأخذ تحميلات المتصفح وتسلّمها لـ Badzy مع الكوكيز والمرجع، فتعمل الروابط التي تحتاج تسجيل دخول |
| 🎞️ **زر على الفيديو** | يظهر زر تحميل على الفيديو مع قائمة الجودات من `yt-dlp` |
| 📃 **قوائم التشغيل** | زر «تحميل الكل» لقوائم تشغيل يوتيوب، وبند في قائمة الفأرة لأي قائمة أو قناة |
| ➕ **إضافة سريعة** | الصق رابطًا عاديًا أو ماجنت في نافذة الإضافة |
| 🧲 **الماجنت** | الضغط على رابط ماجنت في أي صفحة يرسله إلى نافذة التورنت |
| 🈯 **عربي / English** | زر في النافذة لتبديل اللغة، والصفحة تنقلب لليمين تلقائيًا |
| ⏸️ **إيقاف على موقع** | مفتاح في النافذة لترك الموقع الحالي للمتصفح، وقائمة مواقع مستثناة في الإعدادات |
| 🧾 **أنواع ملفات إضافية** | أضف أنواعًا (مثل `iso, apk`) فوق قائمة البرنامج |
| ✅ **علامة الإرسال** | ✓ خضراء على أيقونة الإضافة عند وصول الرابط، و! حمراء إذا تعذّر |
| 🖱️ **قائمة الفأرة** | تحميل رابط، ملف، فيديو، كل روابط الصفحة، الروابط المحددة، قائمة تشغيل؛ وكل بند يمكن إخفاؤه |
| 🔧 **إعدادات** | حد أدنى للحجم، منفذ الاتصال مع زر اختبار، حجم الزر وشكله، تصدير الإعدادات واستيرادها |

### اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Alt` + `Shift` + `B` | فتح Badzy |
| `Alt` + `Shift` + `V` | فتح لوحة تحميل الفيديو للصفحة |
| `Alt` + `Shift` + `L` | إرسال كل روابط الصفحة |
| `Alt` + `Shift` + `P` | إيقاف / تشغيل Badzy مؤقتًا |

يمكن تغييرها من صفحة اختصارات الإضافات في المتصفح.

## 🔍 سلوك البرنامج واتصالاته

| الوظيفة | التفاصيل |
|---|---|
| 🔄 **تحديث البرنامج** | يقرأ `version.json` من أحدث إصدار رسمي في GitHub Releases، ولا يثبّت إلا تحديثًا موقّعًا يطابق المفتاح العام المضمّن في البرنامج، مع التحقق من بصمة SHA-256 |
| 🧰 **الأدوات المساعدة** | `yt-dlp` و`ffmpeg` و`aria2c` في مجلد `tools`؛ ويُحدَّث `yt-dlp` تلقائيًا |
| 🔌 **الاتصال بالإضافة** | منفذ محلي على `127.0.0.1` (الافتراضي 9614) لا يُرى من الشبكة، ويشترط ترويسة خاصة ومصدر إضافة معروفًا، ويرفض طلبات صفحات الويب |
| 🍪 **ملفات تعريف الارتباط** | ترسل الإضافة كوكيز الملف المطلوب وعنوان صفحته فقط، ولا تغادر الجهاز |
| 📋 **الحافظة** | يراقب البرنامج الحافظة ويعرض إضافة أي رابط ملف يُنسخ، ويمكن إيقاف ذلك من الإعدادات |
| 🚀 **التشغيل مع ويندوز** | خيار اختياري يمكن تغييره من الإعدادات |
| 💾 **البيانات** | الإعدادات وقائمة التحميلات محفوظة محليًا على جهازك |

البرنامج والإضافة **لا يجمعان ولا يرسلان** أي بيانات استخدام أو إحصاءات.

## 🛠️ البناء من الشيفرة المصدرية

**الطريقة السهلة:** شغّل **`BUILD.bat`** وسيجهّز الأدوات ويبني البرنامج وينتج `dist\Badzy-Setup.exe`.

**للمطورين** (Rust و MSVC مثبّتان):

```powershell
cargo build --release          # target\release\Badzy.exe
cargo test --workspace         # اختبارات المحرك والبرنامج
node extension/test/background.sim.js   # اختبارات الإضافة
```

كل دفعة إلى GitHub تبني البرنامج تلقائيًا (GitHub Actions)، وتختبر التثبيت الصامت والأدوات، وتنتج الملف `Badzy-windows` للتجربة. تفاصيل أكثر في `docs/BUILDING.md`.
